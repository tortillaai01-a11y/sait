# КОМ-АВТО · локальная версия по Issue №2

Рабочая ветка `codex/kom-avto-cinematic-rebuild` создана от `main`.

## Запуск

В каталоге `sait` с Node.js 22 выполните:

```sh
npm ci
npm run dev
```

Откройте [локальную главную](http://127.0.0.1:5173/). На Windows можно выполнить те же команды через `npm.cmd`. Для проверки сборки выполните `npm test` и `npm run build`.

## Что изменилось

- Первый экран использует утверждённый снимок владельца, оригинальный логотип и живой текст. Оригинал сохранён в `public/images/hero-truck.png`, браузеру предлагается оптимизированный `public/images/hero-truck.webp` (109 КБ).
- Три кнопки ведут к направлениям, где доступны звонок и ссылки на существующие страницы. Добавлены блок «Как мы работаем», контакты и мобильное меню.
- Вместо 3D-сцены используются лёгкое смещение фото на десктопе и анимация появления блоков. Настройка уменьшенного движения отключает эффекты. Three.js исключён из зависимостей.

## Проверки

- `npm ci`, `npm test` (6 тестов), `npm run build` и локальный запуск Vite.
- Edge через Playwright на ширинах 1920, 1440, 1280, 768, 390 и 360 px. Проверены загрузка WebP, отсутствие горизонтальной прокрутки, видимость трёх кнопок на первом экране, мобильное меню, переходы к направлениям и номера в ссылках. Проверены `/truckrepairs`, `/cargotransportation`, `/contacts`, `/privacy` и режим уменьшенного движения.
- Скриншоты первого экрана: [компьютер 1440 × 900](desktop-1440x900.png) и [телефон 390 × 844](mobile-390x844.png).

Проверки звонков, Telegram и почты ограничены адресами ссылок. Отправка сообщений и развёртывание сайта не выполнялись.
