# КОМ-АВТО — один анимированный макет (рабочая ветка)

Ветка: `codex/kom-avto-cinematic-rebuild`. Действующий сайт `kom-avto.ru` и ветка `main` не изменяются. Публикация запрещена до утверждения.

## Запуск на Windows / VS Code

В каталоге проекта `sait`:

```powershell
git status
git switch codex/kom-avto-cinematic-rebuild
git pull --ff-only origin codex/kom-avto-cinematic-rebuild
npm ci
npm run dev
```

Открыть адрес, который выведет Vite (обычно http://127.0.0.1:5173/).

**Важно:** если в VS Code уже есть незакоммиченные изменения, не выполняйте `git switch`/`git pull` поверх них — сначала сохранить/закоммитить текущую работу и согласовать с Codex.

## Сцены

1. Интро — «От детали до дороги». Логотип из исходного файла. Индустриальный фон и вращающиеся световые кольца.
2. Запчасти — макросцена механизма, круговое раскрытие изображения и сканирующая световая полоса.
3. Сервис — эффект кинематографичного вытирания изображения, промышленный свет, описание ремонта.
4. Перевозки — утверждённое фото фуры `public/images/hero-truck.webp`, раскрывающееся из горизонтального светового шва.
5. Контакты — отдельный финальный экран.

Главы удерживаются в кадре через CSS `position: sticky`. Параметры привязаны к фактическому положению скролла и пересчитываются через `requestAnimationFrame`. Прокрутка назад воспроизводит переходы в обратную сторону. Навигация позволяет переходить сразу к нужному направлению.

## Медиа

Фотография фуры и оригинальные файлы фирменного знака — локальные, из репозитория, без изменений. Для разделов запчастей и сервиса сейчас использованы **временные свободно лицензированные фотоматериалы Unsplash**, которые подгружаются из интернета:

- https://unsplash.com/photos/a-close-up-view-of-the-engine-of-a-truck-CcN73HBXNkU
- https://unsplash.com/photos/mechanic-inspecting-a-car-engine-with-hood-open-erWc6mrOq_I

**Эти временные фотографии не изображают реальный сервис компании.** Если интернет/ресурс недоступен — отображаются визуальные запасные фоны. Перед окончательным дизайном нужны качественные согласованные фотографии деталей и грузового сервиса или созданные специально медиасцены; в окончательную сборку медиа необходимо загрузить локально.

## Что проверено

- JavaScript синтаксически разобран без ошибок.
- Проверена сборка HTML-разметки в имитации DOM и наличие четырёх глав и обработчиков.
- Сбалансированы скобки CSS и проверены ключевые анимационные свойства.

**Не проверено на настоящий момент:** `npm ci`, `npm test`, `npm run build`, браузерная визуальная проверка и загрузка удалённых фотографий. Эту проверку выполнить в установленном на компьютере Codex/VS Code перед сдачей.

## Ограничения

Это **развивающийся прототип единственного сайта**, а не окончательная голливудская видеосъёмка. Визуальные перемещения реализованы CSS-масками, панорамированием и наложениями, а не видеофрагментами или настоящей многокадровой съёмкой. Старый действующий сайт и содержимое `main` не затронуты.
