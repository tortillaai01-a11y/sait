## Что исправить

1. На странице перевозок общий заголовок сайта и блок обратного звонка показывают номер запчастей, хотя в подвале для перевозок указан другой номер. Использовать контакт соответствующего направления.
2. На странице сервиса сохранились общие формулировки про поставщика запчастей. Заменить их содержанием о ремонте.
3. Есть повторяющиеся тексты вроде «Запчасти для грузовиков Арзамас | грузовые запчасти Арзамас». Написать понятные посетителю тексты без повторов ключевых слов.
4. В полученном robots.txt директивы записаны без двоеточий (`User-agent`, `Disallow manager`, `Sitemap https://...`). Исправить формат и пути при запуске новой версии. Robots.txt не заменяет ограничения доступа к служебным разделам.
5. В sitemap.xml у всех просмотренных записей стоит дата 1970 года. Указывать реальные даты изменения либо не добавлять lastmod.
6. Главная отправляет формы на `https://www.kom-avto.ru/`, внутренние страницы используют относительные action. Выбрать канонический домен и единый обработчик. Реальную доставку старых заявок проверить отдельно.
7. В HTML шаблон телефона содержит два обратных слеша перед плюсом; при реализации новой формы проверить совместимость pattern с современными браузерами и удобство ввода. Работоспособность старого поля браузерным тестом не подтверждена.

## Рекомендуемая новая версия

Стиль: современный промышленный сайт. Графитовый фон, белые секции, жёлтый акцент; больше свободного пространства и единая типографика. В текущем CSS уже есть графитовый `#252525`, жёлтый `#f7d400`, красно-оранжевый `#f34b17`; можно сохранить узнаваемость, сократив число конкурирующих акцентов. Использовать настоящие фотографии компании, техники, склада и сервиса; не выдавать стоковые изображения за собственный автопарк.

Главная:

1. Логотип, три направления, контакты, кнопка связи.
2. Крупный заголовок «Запчасти, сервис и перевозки для грузового транспорта»; подзаголовок с реальной географией.
3. Три карточки: «Подобрать запчасть», «Записаться в сервис», «Запросить стоимость перевозки».
4. Категории запчастей и марки грузовиков.
5. Порядок работы: заявка → уточнение задачи → предложение → выполнение.
6. Факты о компании, фотографии и отзывы — только предоставленные или подтверждённые владельцем.
7. Контакты по направлениям, адрес, карта по нажатию, форма обращения.

На телефоне: понятное меню, крупные кнопки, быстрый звонок, читаемые формы, отсутствие горизонтальной прокрутки. Учесть клавиатурную навигацию, подписи полей, фокус, контраст и уменьшение анимаций.

Формы новой версии:

- Запчасти: телефон, необязательные имя, VIN/артикул и описание. Загрузку фото вводить только с безопасным серверным обработчиком.
- Сервис: телефон, услуга или описание неисправности, желаемая дата без обещания автоматического бронирования.
- Перевозки: откуда, куда, вес, тип груза, дата, телефон; дополнительные параметры по необходимости.
- Общие требования: серверная проверка, защита от спама, корректные состояния отправки и ошибки, сохранение введённых данных при сбое. Не показывать «Заявка отправлена» без реального успешного ответа сервера.
- Согласие на обработку данных и политика должны соответствовать реальному оператору и процессу; содержание согласовать перед публикацией.
