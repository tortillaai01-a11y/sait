# Проверка интерактивной концепции

Проверено в Chromium через Playwright в облачной среде. WebGL в автоматизированном браузере выполнялся программным растеризатором SwiftShader; это подтверждает рендеринг и взаимодействия, но не устанавливает частоту кадров на реальных телефонах.

- Production-сборка: `npm run build -- --base /sait/`.
- В production-режиме отдельно проверяются CSS главной и внутренних страниц, подкаталог `/sait/`, локальные логотипы и возврат из контактов к направлениям через якорь.
- Создание WebGL-сцены и отображение моделей проверены скриншотами, а не только наличием canvas.
- Проверены четыре главы: собранный грузовик, разбор на узлы, колесо сервиса, маршрут.
- Проверены переходы по кнопкам глав, прокрутка, клавиатурное вращение.
- Все заголовки проверены на ширинах 360, 390, 768, 1024 и 1440 пикселей.
- Проверены окна связи, закрытие Escape, профильный номер перевозок и дополнительный номер владельца.
- Отдельно запущен Chromium с отключённым WebGL: фотография и кнопки связи работают, необработанных ошибок JavaScript нет.
- Проверен режим reduced motion; для ручной остановки автоматического движения есть кнопка паузы.

Логотипы: исходные файлы со старого сайта, соответствуют знаку, предоставленному владельцем. Перерисовки или изменения фирменного названия нет.

Действующий сайт, DNS и хостинг не менялись. Публикация через GitHub Pages требует включить Pages в Settings → Pages → Source: GitHub Actions. Проверенный предыдущий запуск Actions завершился ошибкой `Failed to create deployment (status: 404)` с указанием включить Pages; это ограничение публикации, а не ошибка сборки приложения. После включения можно повторно запустить workflow `Publish website to GitHub Pages`.

До полноценного запуска остаются согласование концепции, оформление внутренних страниц в выбранном стиле, проверка производительности на реальных устройствах, обработчик заявок при необходимости и миграция SEO из REDESIGN-BRIEF.md.
